**Precision CAD, reimagined for the web.**  
A performant, modern CAD application built with Rust & WebAssembly for buttery-smooth drafting in your browser.


---

## ✨ Features
- **⚡ Blazing Fast** - Rust + WebAssembly core for native-like performance
- **🎯 Smart Snapping** - Vertex, orthogonal, and constraint snapping with visual guides  
- **🔄 Full Undo/Redo** - Intelligent state management history
- **🎨 Modern UI** - Clean, intuitive interface with dark/light themes
- **⌨️ Command Palette** - Fuzzy-search commands for power users
- **📐 Precision Tools** - Line, rectangle, circle tools with real-time preview

---

## 🛠 Tech Stack
- **Backend**: Rust + WebAssembly (WASM)
- **Frontend**: React + TypeScript + Vite
- **Rendering**: WebGL2 for hardware-accelerated graphics
- **State**: Custom optimized store with undo/redo
- **UI**: Modern CSS with theme system
